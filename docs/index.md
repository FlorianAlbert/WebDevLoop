# WebDevLoop documentation

WebDevLoop is a local app that turns a GitHub **spec** issue into a stack of draft pull requests. Copilot agents write and review the code. You stay in control and do the final merge.

- **[User guide](user-guide/index.md)**: set it up, queue a spec, follow a run, fix a run that needs attention.
- **[Developer guide](developer-guide/index.md)**: architecture with diagrams and deep dives, for contributors and agents.
- **[Code reference](api/index.md)**: generated from the XML comments in the source.
- **[REST API](rest-api/index.md)**: generated from the OpenAPI document of the app.
